# Agent rules for this code app

This project is a Power Apps code app governed by the Code Apps kit.

- Load the `kit-rules` skill from the `code-apps-kit` plugin before changing, building or deploying this app. If the plugin is not installed, stop and tell the developer.
- `pa app push` from a developer machine is allowed only to the environments listed in `kit.config.json`, only from code that is built, committed and pushed, and always with the developer's confirmation. Other environments are deployed by the pipeline after a merge to `main`.
- Never set the service principal variables (`PA_CLI_USE_SP_AUTH`, `PA_CLI_SP_*`). They belong to the pipeline.
- `src/generated/` and `.power/` are generated by the Power Apps CLI. Do not edit them.
- Call generated services directly (`OrdersService.getAll()`), and only the operations declared under `allowedOperations` in `kit.config.json`. `npm run build` fails on anything else.
- No direct network calls in `src/` (`fetch`, `XMLHttpRequest`, `WebSocket`, `axios`), and no imports of `@microsoft/power-apps/data` in app code.
- `kit.config.json` and `eslint.code-apps-kit.js` hold the kit's rules for this app. Changing them is the developer's decision and is reviewed by the code owners.
